## 清华大学 洪世金： StarryOS 中的 perf 实现

### 报告内容

perf 是 Linux 中常用的性能分析工具，可以统计 CPU 周期、指令数量等信息，并通过采样帮助开发者查找程序中耗时较多的函数。支持这些功能，需要内核配合完成线程调度、硬件计数、中断处理以及用户态与内核态之间的数据传递。

本报告介绍 StarryOS 中 perf 支持的设计与实现。报告以一个数组访问程序为例，通过 Linux 上的测量结果说明 perf 的基本工作原理，随后结合代码，介绍一次测量请求在内核中的处理过程：如何通过 perf_event_open 创建事件，在线程切换时保存计数，并在硬件计数器不足时轮流测量多个事件；如何利用 ARM 性能监测单元（PMU）的溢出中断取得程序执行位置，生成采样记录，再通过共享内存和环形缓冲区供用户态程序读取；以及如何在一次采样中读取同一事件组内的多个计数值，保证中断访问期间相关对象仍然有效。报告还将结合 RK3588 上的测试，分析开发过程中遇到的接口常量错误、共享内存映射属性不一致、对象释放后仍被访问等问题，介绍排查思路、修改依据和测试方法。通过这些具体问题，将操作系统课程中的调度、中断、虚拟内存和同步知识与内核代码联系起来，帮助学生理解如何在已有内核中增加功能、分析故障并检查实现是否正确。

### 报告内容

从 Auto 语言的演进及其融入 Rust 生态的历程讲起，介绍 AutoOS 的桌面应用与发行版路线、AutoUI 的跨平台界面开发，以及 Auto 与 Rust 的语言互操作。重点讲解 AutoVM 解释执行与转译 Rust 发布相结合的开发方式，探讨如何兼顾开发效率、运行性能与安全性。
